# Portafolio

Sitio estático (HTML + CSS). `barberia/` es una copia de la plantilla de `~/Desktop/plantilla-barberia`
en modo Básico (sin Supabase), para que la demo viva en `TU-DOMINIO/barberia/`.

## Publicar gratis en GitHub Pages

1. Crea un repo público llamado `Victor-123321.github.io`.
2. Sube el contenido de esta carpeta a la rama `main`.
3. Queda en `https://victor-123321.github.io` (y la demo en `/barberia/`).

Dominio propio (~$200 MXN/año en Namecheap, Porkbun o Cloudflare): en el repo ve a
Settings → Pages → Custom domain, y en tu proveedor de dominio crea un registro CNAME
que apunte a `victor-123321.github.io`.

## Al actualizar la plantilla

```bash
cp ~/Desktop/plantilla-barberia/{index.html,styles.css,app.js,comun.js,config.js} ~/Desktop/portafolio/barberia/
```
